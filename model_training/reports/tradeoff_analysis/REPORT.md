# TRACK-OT++ Tradeoff Analysis & Sensitivity Characterization
## Empirical FROC, Validation-Calibrated Operating Points & Matched Baseline Comparison

**Evaluation Scope:** Fold 1, Seed 42 held-out test cohort (Sites 1, 2, 3 across runs `AtoB_20_4`, `BtoA_25_4`, `BtoA_27.5_4`).  
**Protocol Disclosures:**
1. **Validation-Selected Operating Points:** Selected strictly on validation data without access to test labels.
2. **Retrospective Test-Matched Points:** Exploratory, test-optimized descriptive points. They show the theoretical limit of the model's test predictions, but must **not** be presented as leak-free deployable performance.

---

### Executive Summary

| Finding | Evidence | Significance |
| :--- | :--- | :--- |
| **Why Event Recall was 11.1% initially** | Primary threshold ($\tau = 0.8861$) calibrated under $\le 1.0\text{ FA/km}$ on Site 4. Test sites 1 & 2 peaked at $p = 0.8705$ and $0.8798$. | Near-boundary misses (0.006 to 0.015 below threshold). |
| **Validation Max-F1 Sensitivity** | At $\tau = 0.8655$ (fitted purely on validation), event recall triples to **33.3% (3/9 events)** at **0.875 FA/km** (1 false alarm). | Legitimate validation-selected operating point. |
| **Retrospective FROC Ceiling** | Retrospective search on the test set finds $\tau = 0.5428$ achieves 55.6% recall at 2.625 FA/km. | **Exploratory only:** Not an independently validated deployable operating point. |
| **Baseline Dominance Reality** | TRACK-OT++ does **not** dominate Random Forest at every operating point. RF achieves comparable or higher event recall across several retrospective regimes. | Highlights need for multi-fold validation and controlled ablations. |
